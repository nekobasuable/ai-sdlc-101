プライバシーポリシー

ふくろう手帳は、開発者本人が個人で使うための、週の計画と振り返りのアプリです。

扱うデータ

  • アプリに入力した項目、計画、記録、メモ
  • Google カレンダーの予定(読み取りのみ)
  • Google ToDo リストのタスク(同期のための読み書き)
  • Google アカウントのメールアドレス(ログインのため)

保存の場所と保護

  • データは Supabase のデータベースに保存し、ログインした本人だけが読み書きできるよう制限しています。
  • Google の連携に使う鍵は、暗号化してサーバー側に保管し、ブラウザには渡しません。
  • 通信はすべて HTTPS で暗号化しています。

利用の目的

データは、このアプリの機能(計画、振り返り、Google カレンダーの表示、Google ToDo リストとの同期)のためだけに使います。広告や分析には使いません。

第三者への提供

データを第三者に販売したり、提供したりすることはありません。Google のユーザーデータの扱いは、Google API Services User Data Policy(Limited Use の要件を含む)に従います。

データの削除

アカウントを削除すると、関連するデータもすべて削除されます。Google アカウントの設定から、このアプリへのアクセスをいつでも取り消せます。
