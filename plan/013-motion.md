## Context
画面は「手帳」の見た目で落ち着いたが、プロダクトオーナーから「テンションが上がるほどではない」との声があった。見本で、時間帯の空、飛ぶふくろう、墨のしぶき、飛んでいく文字、墨の波紋、書き込まれる下書きを試し、「強め」版で OK が出た。
引用は全部で6件しかなく、同じ日の同じ場面なら同じ言葉なので、ほぼ毎日同じ言葉に見える。

見本(強め版)を、今の部品に入れる。動きは CSS のアニメーション(`src/index.css` にまとめる)で作り、JavaScript は始まりのきっかけだけにする。`prefers-reduced-motion` で止める指定を1か所に置く。

### 変更
- **空と紙の色**: `src/ui/Sky.tsx`(新規)。「今」の画面の上に、時間帯の空を墨の線で描く(朝: 日が昇る、昼: 雲、夕方: 低い日と水面、夜: 月と星)。時間帯が変わると描き直す。紙の色は、時間帯ごとの値を `src/domain/period.ts` に置き、`body` に変数で渡して 2〜3秒かけて移す。紙の値と `ink-3` の明暗の差 4.5:1 以上は、単体テストで確かめる。
- **終えた**: `HandCircle.tsx` で、丸を描く動き、チェックを書き込む動き、墨のしぶき(数粒、0.9秒で消える)を付ける。`NowView.tsx` では、名前の下に手書きで「終えた。」を添える(評価の言葉は付けない)。
- **ふくろう**: `Owl.tsx` に、瞬き、寝息、跳ねる(押したとき、終えたとき)、「ほう。」、羽ばたいて移る(居場所が変わったとき: 前の場所から飛び立ち、新しい場所に舞い降りる)を足す。ふくろうは押せるようにする(`button`、44px)。省みる画面では、聞いている間は首をかしげ、整えている間は目をきょろきょろさせ、下書きが出たらうなずく。
- **放り込む**: `Capture.tsx` で、送った文字を一文字ずつ、上の「週」へ飛ばす(行き先は「週」のタブの位置を測って決める)。着いたら「週」に小さな点を灯し、「やることに入った。」と添える。保存に失敗したら飛ばさない(文字は欄に残す。今の動きと同じ)。
- **話して省みる**: `MicButton.tsx` で、聞いている間、マイクのまわりに墨の波紋を広げる。`SpeakReflect.tsx` で、整えている間は話した文字を薄くし、下書きが出たら、左に括弧の線を引いてから4項目を順に書き込む。
- スキル(`.claude/skills/life-dashboard-look/SKILL.md`)に「動き」の節を足す(何に動きを付け、何に付けないか、速さの目安、動きを減らす設定)。

### テスト

## リスク
- **うるさく感じる**: 実際の画面で毎日見ると、見本より強く感じることがある。動きの速さと大きさは CSS の変数にまとめ、あとから一段弱めやすくしておく。
- **夜の紙の色**: 暗めの紙で薄墨の文字が読みにくくなりうる。明暗の差のテストで防ぐ。
- **電池と重さ**: 動き続けるもの(瞬き、寝息、星)は小さな SVG だけにする。

## 計画からのずれ
- ふくろうの「羽ばたいて移る」は、羽を広げた絵で前の場所から次の場所へ飛ぶ形ではなく、新しい場所に舞い降りる動き(`owl-land`)にした。今の画面では、ふくろうの居場所ごとに別の部品として置いているため、居場所が変わると新しい場所に現れる。そのときに舞い降りるので、「居場所が変わったかどうかの判定」は純粋な関数にせず、テストも足していない。
- 開いたときにも、ふくろうは舞い降りる(居場所が変わったときと同じ動き)。
- 省みる画面のふくろうは、ふだんは本を読む姿のまま。聞いている間、整えている間、下書きが出たときだけ、起きている姿で首をかしげ、目をきょろきょろさせ、うなずく。
- 下書きの左の括弧の線は、SVG の括弧ではなく、上から引かれる一本の罫線(`draw-down`)にした。下書きの高さが中身によって変わるため。
- ふくろうを `button` にした(押すと跳ねて「ほう。」)。眠っている姿は、押しても起こさない。
- 動きの確かめ: ログイン画面で、ふくろうが描かれ、押すと跳ねて「ほう。」と出ることを、Playwright の画像で確かめた。ログインしたあとの画面(空、終えた、放り込む、話して省みる)は、この作業環境では本番のデータにつなげないため、プロダクトオーナーの目で確かめる。
- PR #17 のレビューの指摘で直した: 開いたときの読み込みやブロックの切り替えで、ふくろうが跳ねていた。同じ配置が「終えた」に変わったときだけ跳ねるようにした。話して省みるの途中で週を切り替えたとき、ふくろうを元の姿に戻すようにした。
- 聞いている間のマイクの波紋は、聞いているあいだ動き続ける。操作への応答として、その間だけ動き続けてよいものとしてスキルに書いた(R43 の「動き続けるもの」の例外)。
