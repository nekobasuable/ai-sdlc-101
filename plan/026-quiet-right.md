# plan/026-quiet-right: 右の列を静かに(一言を左へ、罫線をなくす、墨の点)

- 元: プロダクトオーナーの声(2026-11-27)。
  - 「今日の一言だけは、画面の左とかに移す？　右側がビジーだよね」
  - 「やること1個ずつで横棒は入れなくていいかな」
  - 「箇条書きのが『-』なのはちょっと見づらいかも」→ 印は「墨の点」を選んだ。
- 状態: 承認済み(2026-11-27)
- あわせて、PR #25 のレビューの Nit 2件を直す

## Context
- 「今」の画面の右の列に、今日のこれから・一言・タスクの追加・やることが縦に並び、混んで見える。
- やることの行のあいだの薄い罫線と、頭の短い墨の線が、細かく区切られた印象を与えている。

## spec(R47、R17a の補足。意味は変わらないので変更番号は振らない)
- R47(補): 頭の印は、小さな墨の点にする。行のあいだの罫線は引かない(行の余白で区切る)。
- R17a(補): 「今」の画面では、左の列に置く。

## 変更
- `src/ui/App.tsx`: `DailyNote` を右の列から左の列(`main`)に移す。置く場所は「今日までのこと」の下。夕方から次の朝までだけ出す決まり(`dailyNoteSlot`)はそのまま。スマホでは左の列が先に並ぶので、今のブロックと今日までのことの後に出る。
- `src/ui/ListMark.tsx`: 短い線をやめ、小さな墨の点にする。
  - 径は約 5px。筆で置いたように、少しいびつな形にする(SVG の path)。
  - 色は `ink-2`。今の線(`ink-3`)より濃くして、見やすくする。
  - 位置は、文字の中央の高さにそろえる。使っている所(やること、月の日の一覧、人生の柱)で位置を確かめる。
- 行のあいだの罫線(`border-b border-rule-soft`)をなくす:
  - やることの一覧(`InboxList.tsx` の行)。
  - 今日までのこと(`TodayDue.tsx`)。
  - 月の日の一覧(`MonthView.tsx` の `DayList`)。
  - 人生の柱の欄(`PillarsEditor.tsx`)の下線は、書き込める欄の印なので残す。
- `.claude/skills/life-dashboard-look/SKILL.md`: 一覧の決まりを「墨の点、罫線なし」に直す。
- PR #25 のレビューの Nit:
  - `DueField.tsx`: 何も選んでいないときは、欄の外を押したとき、またはほかの欄へ移ったときに閉じる(下の「計画からのずれ」を参照。plan/027 で文言を直した)。
  - `DailyNote.tsx`: 11時に欄が消えるときの保存に失敗したら、その下書きは残らない。11時ちょうどに書きかけで、しかもつながっていないときだけ起きる。頻度が低いので、知らせる場所は作らず、この扱いを plan に記録するだけにする。

## やらないこと
- 右の列のほかの並びは変えない(今日のこれから → タスクの追加 → やること)。

## 計画からのずれ
- 日付の欄を閉じる決まり(PR #25 の Nit): 「少し待ってから閉じる」はやめた。日付の選び方を開いている時間は人によって長く、待つ時間を決められないため。代わりに、何も選んでいないときは、ページの欄の外を押したとき、またはほかの欄へ移ったときに閉じる。OS の日付の選び方が開いているあいだはページが押されないので、選んでいる途中で閉じることはない。
