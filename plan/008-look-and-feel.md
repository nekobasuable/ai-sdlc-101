# plan/008-look-and-feel: 見た目を「手帳」に作り直す

- 元: spec の変更 2(R35〜R37)、スキル `.claude/skills/life-dashboard-look/SKILL.md`、デザインの見本(案1-b 手帳、夜、PC)
- 状態: 承認済み(承認者: リポジトリオーナー、2026-11-23)
- 承認後、この内容を `plan/008-look-and-feel.md` としてコミットしてから実装に入る。

## Context
画面を見たプロダクトオーナーから「技術力のない人が作ったモックのよう」と指摘があった。Design 段階で見た目を決めていなかったため。
見本を作って方向性(案1-b 手帳)を決め、スキルとして書き残した。この plan で、今ある画面をすべてその方針で作り直し、PC でも2列の配置にする。
plan/007 の残り(段階 B〜D)は、この plan のあとに、新しい見た目のまま作る。

## 対象の画面(すべて src/ui/)
| 画面 | 作り直し方 |
|---|---|
| ログイン(`SignIn`) | 紙の上に、名前と一言、「Google でログイン」を言葉として置く |
| 今(`NowView`、`App`) | 案1-b: 今やることを Zen Old Mincho で大きく。手描きの丸で「終えた」、その下に「途中まで」「今日は手放す」。今日のこれからを文章で。引用を1つ。下線だけの入力欄 |
| 週(`WeekView`) | 案1 の週を手帳の書体で。日ごとに、過ぎた・今・これからを文字の濃さで分ける。何もない日は「余白の一日」。上に「一週間は、今の積み重ね。」 |
| Inbox(`InboxList`) | 折りたたみは残し、「ふと浮かんだこと」として文章の一覧に。「今やる」は言葉のまま |
| Google ToDo の同期(`SyncSettings`) | 設定らしさを抑え、下の方に小さく。チェックボックスと選択欄は残す(機能は変えない) |
| 入力(`Capture`) | 下線だけ。Klee One |

## 新しく作るもの
- **書体と色**: `index.html` で Google Fonts(Zen Old Mincho、Klee One、Zen Kaku Gothic New)を読み込む。Tailwind の設定(`src/index.css` の `@theme`)に、スキルの色と書体を名前付きで登録し、画面からは名前で使う(`bg-paper`、`text-ink`、`font-hand` など)。
- **手描きの丸**: `src/ui/HandCircle.tsx`。終えたら中にチェックを描く。
- **ふくろう**: `src/ui/Owl.tsx`(姿を3つ: 見守る、眠る、本を読む)と、`src/domain/owl.ts`(時間帯と日付から、姿と居場所を決める純粋な関数。単体テスト必須)。
  - 0〜5時と夜は眠る、昼のブロックは見守る、余白のブロックは本を読む。居場所は日付で決まる候補(見出しの横、画面の下の隅、今日のこれからの横)から選ぶ。同じ日の同じ時間帯なら同じ結果。
- **引用**: `src/domain/quotes.ts` に、出典を確かめられた言葉を数件(マルクス・アウレリウス、セネカ、老子、ヘーゲル)。場面と日付で1つ選ぶ。R18、R19 の最初の一歩。出典の確かめ方は、日本語訳の言い回しを避けて意味を保つ言い換えにし、人物と著作を添える(C3)。
- **PC の2列**: 幅 1024px 以上で、今の画面を左(今やること)と右(今日のこれから、入力欄)の2列に。週の画面は中央に寄せ、最大幅を決める。
- **言葉の置き換え**: やった → 終えた、一部 → 途中まで、やらなかった → 今日は手放す、振り返り → 省みる(画面の表示だけ。データの値は変えない)。

## やらない
機能の追加(週の画面の配置の仕組みや、同期の動きは変えない)。plan/007 段階 B〜D。動き(アニメーション)。

## 作業の順序
1. 書体と色の登録、手描きの丸、ふくろうと引用の中身の計算(テスト付き)
2. 今の画面とログイン(スマホ → PC の2列)
3. 週、Inbox、入力、同期の設定
4. PR を作る。CI と AI レビュー(REVIEW.md の見た目の観点を含む)を通す
5. マージ後に、あなたにスマホと PC で見てもらう

## リスク
- **見本と実物のずれ**: 見本は固定の例、実物は本物のデータ。項目名が長い、予定が多いなどで崩れうる。長い文字は折り返し、項目が多いときも落ち着いて見えるかを確かめる。
- **書体の読み込み**: 日本語の書体は重い。`display=swap` で、読み込みの間も文字は出す。
- **画面の確認が手動**: 見た目はテストできない。マージ後にあなたに見てもらい、違和感は次の PR で直す。
- **引用の正確さ(C3)**: 確かめられない言葉は入れない。

## 証明(Proof)
- `npm run lint`、`npm test`(ふくろうと引用の選び方のテストを含む)、`npm run build` が通る。CI と AI レビュー(Important 0 件)を通る。
- あなたの確認:
  - スマホで、今・週・Inbox・入力が「手帳」の見た目になっている。箱型のボタンやカードが残っていない。
  - PC で、今の画面が2列になっている。
  - ふくろうが、時間帯で居場所と姿を変えている(昼と夜で見比べる)。
  - 記録(終えた・途中まで・今日は手放す)、置く・外す、放り込む、同期が、今までどおり動く。

## 計画からのずれ
- スキルの薄墨の色(`#8C8276`、`#A89E90`)は、紙の色の上で文字の明暗の差が 4.5:1 に届かなかった。一段ずつ濃くし(`ink-2`〜`ink-4`)、スキルの表を実装の値に合わせて直した。
- 「終えた」の丸は、もう一度押すと「途中まで」に戻せるようにした(押し間違いを戻せるように)。結果を付ける前は「ここから外す」も出す(今の画面から Inbox に戻す、R14a)。
- 週の画面の配置の操作は、ブロックごとの「置く」から、日ごとの「描く」→ ブロック名を選ぶ → 候補を選ぶ、に変えた。日ごとに6つの枠を並べると表に見えるため(スキル: 表ではなく文章で)。予定のあるブロックだけを文章で並べ、何もない日は「余白の一日」とした。
- 「省みる」のタブは、plan/007 段階 D で作るまで出さない(押しても何もない入り口を置かない)。
- 入力欄は、スマホでは画面の下に固定、PC では右の列の中に置いた。
