# plan/025-capture-details: タスクの追加を整える(締め切りとメモ、置き場所)と、一言を夕方から

- 元: プロダクトオーナーの次の声から。
  - 「追加時も、日付とか詳細を入れられるようにしたいな」
  - 「ふと浮かんだことっていうのもわかりずらいから、『タスクの追加』でいい気がする」
  - 「今日のことを一言だけにはマイクが欲しい。タスク追加の方が、むしろパッとタスク追加するだけだからマイクいらない」
  - 「今日のことを一言を、どっか別のところに移せばビジーじゃなくなるかな？　タスク追加はやることの上にあったほうがいい」
  - 一言の場所は「夕方からだけ出すのに賛成。次の日の朝に入れるパターンも許容したい」
- 状態: 承認済み(2026-11-26)
- spec の変更 14(下記)

## 置き場所と一言(この節を先に読む)
- **タスクの追加:**
  - 欄の文言を「ふと浮かんだことを」から「タスクの追加」にする。
  - マイクのボタンは外す(声で入れたいときは、スマホのキーボードのマイクが使える。spec R2 の元の形)。
  - 「今」の画面では、やることの一覧のすぐ上に置く。スマホの画面の下に固定していたのをやめ、流れの中に置く。
  - 週・月・省みるの画面は、今のまま下に置く(どの画面からでも追加できる、R1)。
- **今日のことを、一言だけ(R17a):**
  - 「今」の画面には、夕方(17時)から次の朝(11時)までだけ出す。昼のあいだは出さない。
  - 夕方と夜(0〜5時を含む)は「今日のことを、一言だけ」で、その日の一言。
  - 朝(5〜11時)は「昨日のことを、一言だけ」で、前の日の一言。書いてあればそれを見せ、直せる。
  - 一言の欄にマイクを付ける(`MicButton` と `useSpeech` を、今の追加の欄から移す)。
  - `src/domain/daily-note.ts`(新規、テスト付き): 時刻とタイムゾーンから、出すかどうか、どの日か、見出しの言葉(今日/昨日)を返す。`period.ts` の `periodOf`、`periodDay` を使う。
- spec R17a(補): 上の時間帯の決まりと、マイクを足す。

## Context
- トップ画面の「ふと浮かんだことを」は、題名だけを入れる。
- 締め切りは Google ToDo から取り込んだときにしか付かない。spec R7「締め切りを任意で付けられる」に当たる場所が、アプリにない(作り忘れ)。
- メモは、追加したあとに詳細を開けば書ける。追加するときには書けない。
- 同期は、締め切りもメモも Google ToDo に送れる形になっている(`_shared/sync.ts` の `toGoogle`、`updated_at` のトリガーは `due_date` と `notes` の変更で進む)。サーバー側とデータベースは変えなくてよい。

## spec の変更 14(この plan の承認で受理とする)
- R7(補): 締め切りは、追加するときにも、詳細を開いたときにも、付けられる。直すことも外すこともできる。
- R51(新): 追加の欄で、題名に加えて、締め切りとメモを任意で入れられる。入れる欄は、題名を書き始めてから小さく現れる。何も書いていないときは、今の一行のまま(余白、P2)。

## 変更
### データ
- `src/data/items.ts`:
  - `addItem(body, { dueDate, notes })`。空のメモは `null`(Google に送らない)、空の締め切りも `null`。
  - `saveDueDate(itemId, dueDate | null)` を足す。
- `src/domain/capture.ts`(新規、テスト付き): 入力の値を保存する形に整える。
  - 前後の空白を取る。空なら `null`。
  - 日付は `YYYY-MM-DD` の形だけを受け付ける。

### 画面
- `src/ui/Capture.tsx`(トップ画面の追加の欄):
  - 題名を書き始めると、欄の下に「〆」と「メモ」が薄く現れる。
  - 「〆」を押すと、日付を選ぶ欄(`<input type="date">`)が開く。スマホでは OS の日付の選び方が出る。選んだ日は「〆 11/28」と示し、「外す」で消せる。
  - 「メモ」を押すと、メモの欄が開く。詳細のメモと同じく、書いた分だけ縦に広がる(高さを合わせる処理を詳細と共通にする)。
  - 題名の欄で Enter を押すと、今までどおり送る。メモの欄の Enter は改行。→ のボタンで送る。
  - 送ったら、題名、締め切り、メモを空にして閉じる。文字が飛ぶ動きは今のまま(題名だけ)。
  - マイクは外す(上の節)。
- `src/ui/ItemDetail.tsx`: 一行目の「〆 11/28」を押すと日付の欄が開き、直せる。締め切りがないときは「〆 を付ける」。外すこともできる。
- 高さを合わせる処理(`fitHeight`)を `src/ui/auto-height.ts` に移し、詳細と追加の両方で使う。
- 文言は命令形にしない(「〆」「メモ」「外す」)。色は今の薄い墨のまま。

### 同期
- 変更なし。アプリで追加した項目は、柱に結びついたリスト、なければ既定のリストに作られ、締め切りとメモも一緒に送られる。詳細で直した締め切りも、次の同期で Google ToDo に届く。

## やらないこと
- 声で言った日付(「金曜まで」など)を読み取って締め切りにすること。
- 時刻の付いた締め切り。Google ToDo の API は日付しか扱えない。
- 追加のときに人生の柱や局面を選ぶこと。AI の見立てに任せ、詳細の「直す」で直す。

## 証明(Proof)
- `npm run lint`、`npm test`(`capture.ts` のテストを含む)、`npm run build` が通る。CI と AI レビュー(Important 0 件)を通る。
- Playwright(ダミーのデータ)で、スマホ幅と PC 幅について次を確かめる。
  - 題名を書く前は一行のまま。
  - 書くと「〆」「メモ」が出る。
  - 日付とメモを入れて送ると、保存の呼び出しに `due_date` と `notes` が入る。
  - 詳細で締め切りを付けられ、外せる。
  - 「今」の画面で、タスクの追加がやることの一覧のすぐ上にあり、マイクがない。
  - 時刻を変えて撮り、一言が昼は出ず、夕方は「今日の」、朝は「昨日の」で出て、マイクがある。
  - 横にはみ出さない。
- あなたの確認(マージ後): 締め切りとメモを付けて追加したものが、「やること」と週・月の画面に締め切りつきで出るか。Google ToDo にも日付とメモつきで届くか。

## 計画からのずれ
- `addItem` は `addItem(body, { dueDate, notes })` ではなく、整えた値をまとめて受け取る `addItem(fields)` にした(`src/domain/capture.ts` の `captureFields` の結果をそのまま渡すため)。音声で省みるから足すところ(`SpeakReflect.tsx`)も同じ形にした。
- 詳細で締め切りがないときの文言は「〆 を付ける」ではなく、追加の欄とそろえて「〆」だけにした(押すと日付の欄が開く)。
- 日付の欄は、選んでいるあいだの値を手元に持ち、欄を離れたとき(または Enter)に1回だけ渡すようにした。キーボードで年を打つ途中の値(0002-11-28 など)で保存されたり、既存の締め切りが外れたりしないため(PR #25 のレビューの指摘)。年は 2000〜2100 に絞る。何も選ばないうちに離れても閉じない(日付の選び方を開くと先に欄から離れる端末があるため。Esc で閉じる)。
- 一言の欄は、11時に消えるとき(日付が変わるとき)にも、離れる前の下書きを残す(PR #25 のレビューの Nit)。
