# plan/014-quotes: 言葉の巡り

- 元: プロダクトオーナーの要望(「もっとダイナミックで動的に」「哲学の引用のバラエティーが少ない。1か月は同じのが出ない、毎回変わるくらい」)。動きは見本(Artifact「手帳の動き」の下の段、強め版)で決定。言葉は「時間帯ごとに変わる」を選択。spec の変更 7
- 状態: 承認済み(承認者: リポジトリオーナー、2026-11-26)
- plan/013(動き)と同時に承認。こちらを先に出す(小さく、先に出せるため)

## Context
画面は「手帳」の見た目で落ち着いたが、プロダクトオーナーから「テンションが上がるほどではない」との声があった。見本で、時間帯の空、飛ぶふくろう、墨のしぶき、飛んでいく文字、墨の波紋、書き込まれる下書きを試し、「強め」版で OK が出た。
引用は全部で6件しかなく、同じ日の同じ場面なら同じ言葉なので、ほぼ毎日同じ言葉に見える。

## spec の変更 7(この plan と plan/013 の承認で受理とする)
- R43(新): 画面は、操作したときと時間の移り変わりに、手で書くような動きで応える。ずっと動き続けるのは、ふくろうの瞬きと寝息、夜の星のまたたきだけにする。端末で動きを減らす設定(`prefers-reduced-motion`)のときは動かさない。
- R44(新): 1日を4つの時間帯(朝 5〜11時、昼 11〜17時、夕方 17〜20時、夜 20〜5時)に分け、時間帯ごとに、空の絵と紙の色合いを変える。文字の明暗の差は、どの時間帯でも保つ(4.5:1 以上)。
- R18(改): 言葉は、時間帯ごとに変わる。同じ時間帯のあいだは同じ言葉。それぞれの画面で、30日のあいだは同じ言葉が出ない。同じ時刻の画面どうしでは、別の言葉が出る。
- R19(改): 収録の目安を 20〜40件 から 130件ほどに改める(夜の言葉 35件ほど、それ以外 95件ほど)。出典の確認(C3)は変えない。
- R36(補): ふくろうは、時間帯が変わると羽ばたいて居場所を移る。押すと跳ねて「ほう。」と一言いう。

### 変更
- `src/domain/period.ts`(新規): `periodOf(now, timeZone)` → `'morning' | 'noon' | 'evening' | 'night'` と、巡りの番号 `periodIndex(now, timeZone)`(日の番号 × 4 + 時間帯。0〜5時は前の日の夜)。`time.ts` の `zonedParts` を使う。plan/013 の空と紙の色もこれを使う。
- `src/domain/quotes.ts`:
  - `Scene` を `'general' | 'night'` の2つの言葉の束にする。`day` / `week` は使わない(週と省みるも、時間帯で巡る)。
  - `pickQuote(screen, now, timeZone)`: 夜の時間帯は夜の束、それ以外は一般の束から選ぶ。束の中の位置は、巡りの番号を、その束での順番(夜は日ごとに1つ進む、一般は時間帯ごとに1つ進む)にして決める。画面ごと(`now` / `week` / `review`)に束の 1/3 ずつずらして、同じ時刻の画面どうしで重ならないようにする。
  - 束が 1日に進む数 × 30 より大きいので、それぞれの画面で 30日は重ならない(一般: 3 × 30 = 90 < 95、夜: 1 × 30 = 30 < 35)。
  - 言葉を 130件ほどに増やす。古典(著作権の切れたもの)から、意味を保った言い換えにして、人物と著作(わかるときは章や節)を添える。候補: マルクス・アウレリウス『自省録』、セネカ『人生の短さについて』『倫理書簡集』、エピクテトス『要録』、老子『道徳経』、荘子、『論語』、兼好『徒然草』、鴨長明『方丈記』、道元『正法眼蔵』、パスカル『パンセ』、モンテーニュ『エセー』、スピノザ『エチカ』、ソロー『森の生活』、エマソン、キルケゴール、ニーチェ、芭蕉、良寛 など。出典に自信の持てないものは入れない。
- `src/ui/QuoteLine.tsx`: `scene` と `date` の代わりに `screen` と `now` を受ける。呼んでいる3か所(`App.tsx`、`WeekView.tsx`、`ReviewView.tsx`)を直す。
- 時間帯が変わったとき、開いたままでも言葉が変わる(`App` の `now` はすでに定期的に進んでいる)。

### テスト(`quotes.test.ts`、`period.test.ts`)
- 時間帯の境目(4:59、5:00、10:59、11:00、16:59、17:00、19:59、20:00、0:30 は前の日の夜)。タイムゾーンをまたぐとき。
- それぞれの画面で、30日分の全時間帯を並べたとき、同じ言葉が出ない。
- 同じ時刻の3画面で、言葉が重ならない。同じ時間帯のあいだは同じ言葉。
- すべての言葉に人物と出典がある。本文に重複がない。長さは 50 文字以内(1〜2行に収まる)。

## 計画からのずれ
- 収録は一般の束 95件、夜の束 34件の計 129件。書いている途中で、出典に自信の持てないもの3件(ソロー『森の生活』「孤独」、モンテーニュ『エセー』2巻6章、良寛の詩)を外し、出典の確かなものに差し替えた。
- 季節の言葉(枕草子、芭蕉、蕪村)も入れた。時間帯には合わせず、一般の束と夜の束に分けただけにした。
