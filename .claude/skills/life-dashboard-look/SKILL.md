# life-dashboard の見た目と手触り

方向性は「手帳」。思索のための手帳や日記のように、思慮深さとセンスと哲学的なテイストがいい塩梅に感じられること。わざとらしくしない。技術的な道具に見せない。
決めた経緯と見本: intent の「見た目と手触り」、spec の 5章、デザインの見本(案1-b 手帳)。

## 色
紙と墨の二色に近い。評価の意味を持つ色(赤、緑、警告の黄色)は使わない(spec R16)。

| 用途 | 値 |
|---|---|
| 紙(背景) | `#F3EFE7`(`paper`) |
| 墨(本文、主要な文字) | `#2E2A25`(`ink`) |
| 薄墨(予定の文章、補足) | `#5A5248`(`ink-2`) / `#6F665A`(`ink-3`) |
| さらに薄い墨(余白、手放すなど控えめなもの。大きめの文字か、読めなくても困らない飾りだけ) | `#8C8276`(`ink-4`) |
| 罫線 | `#D6CDBE`(`rule`。区切り線は `#E2DACC`、`rule-soft`) |

括弧の名前は `src/index.css` の `@theme` に登録した Tailwind の色名(`text-ink-3`、`bg-paper` など)。
見本の薄墨(`#8C8276`、`#A89E90`)は紙の上で文字の明暗の差が足りなかったため、実装では一段濃くした(plan/008)。

## 書体(Google Fonts)
| 書体 | 使う場所 |
|---|---|
| Zen Old Mincho | 今やることの名前、画面の大きな見出し、引用 |
| Klee One(手書き風) | 本人の言葉と手の動き: 日付、入力欄、一日の一言、控えめな操作(途中まで、今日は手放す) |
| Zen Kaku Gothic New(400) | それ以外の文字(説明、予定の文章、ナビゲーション) |

欧文のイタリック体や、教科書のような古典的なセリフ体は使わない(教科書っぽく見えるため)。

読みやすさを優先する(spec R46、plan/016)。Zen Kaku Gothic New は 400 の太さで使う(300 は Windows で細すぎた)。本文は 15px 以上、補足は 13px 以上。小さな見出し(「午前のあいだ」「今日のこれから」など)は `label`(13px、字間 0.08em、`ink-2`)を使い、字間を広げすぎない。やることや予定など、読ませたい本文は `ink`(墨)にする。

## 部品の作り方
- **ボタンを箱にしない**: 塗りつぶしや枠付きの丸いボタン(ピル型)、カード、影、グラデーションは使わない(AI が作ったように見えるため)。操作は言葉そのものか、手で描いたような線にする。
- **終えた**: 手で描いたような丸(少しゆがんだ円の線)。押すとチェックが入る。
- **途中まで、今日は手放す**: Klee One の小さな言葉を、終えたの下に控えめに並べる。
- **入力欄**: 枠を付けず、下線1本だけ。
- **予定や今日のこれから**: 表ではなく文章で書く(「午後には、〜する。」「昼と夜は、まだ何も決めていない。」)。
- **余白**: 何もない時間は「余白」「何も決めていない」と、肯定的に、薄墨で書く。空欄を「足りないもの」に見せない(P1、P2)。
- 押せる場所は 44px 以上。文字の明暗の差を保つ(薄墨でも読めること)。

## ふくろう
- 墨の線で描いたオリジナルのふくろう(既存のキャラクターをまねない)。大きさは 40〜50px 程度で、主張しない。
- 時間帯と日付で、居場所と姿が変わる(見守る、眠る、など)。同じ日の同じ時間帯なら同じ姿。ランダムにしない。
- 説明はしない。気づく人が気づく程度。

## 言葉づかい
- 命令形や警告の口調にしない(R23)。「〜してください」より「〜する」「〜を。」。
- 使う言葉: 今 / 週 / 省みる、終えた / 途中まで / 今日は手放す、余白、やること(一覧の名前)、ふと浮かんだことを(入力欄)、今日までのこと(締め切り)、今日のことを一言だけ。
- 予定を置く入り口は、言葉ではなく、日付の横のさりげない「+」にする(押せる範囲は 44px)。
- 哲学者や思想家の言葉は、1画面に1つだけ、小さく、出典を添えて置く(R18、R19)。飾りにしない。

## 配置
- スマホ: 1列。上から、日付とナビ、今やること、今日のこれから、引用、入力欄。
- PC(幅 1024px 以上): 2列。左に今やることを大きく、右に今日のこれから、一日の一言、入力欄。外側の余白を大きく取る(左右 72px 程度)。スマホの画面を引き伸ばさない。
